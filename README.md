# Optimization Rocket

基于 CasADi/IPOPT 的运载火箭上升段轨迹优化与推力故障可达域分析项目。

项目研究的问题是：一级发动机在不同飞行时刻发生不同程度的推力衰减后，能否通过重构程序角、调整一级分离时刻和延长二级末段工作时间重新进入目标轨道；如果能够补偿，不同策略需要付出多少一级工作时间、二级工作时间和推进剂代价。

物理模型是一枚两级运载火箭。为了准确处理故障、一级分离和整流罩分离等离散事件，数值模型按事件划分为多个动力学阶段；“三自由度”表示三维质点平动模型，不表示三级火箭。

## 研究内容

- 建立包含地球自转、J2 重力、指数大气、气动阻力、质量消耗和级间质量跳变的三自由度动力学模型。
- 使用 RK4 直接转录，将连续最优控制问题离散为非线性规划，并由 CasADi 构造、IPOPT 求解。
- 建立一级推力衰减故障模型，并在故障后联合优化俯仰/偏航程序角、一级分离时刻和二级末段工作时长。
- 设计 S0–S3 四类时序补偿策略，比较一级补偿、二级补偿和联合补偿对可达域的影响。
- 扫描故障时刻 `te` 与推力衰减比例 `kappa`，统计可达性、一级补偿量、二级补偿量、剩余推进剂和末端质量。
- 通过边界二分、终端容差对比和动力学回放，区分能量不足、控制能力限制、轨道相位约束和数值不收敛。

## 动力学与故障模型

状态和控制定义为：

```text
x = [rx, ry, rz, vx, vy, vz, m]
u = [phi, psi]
```

其中 `r`、`v` 分别为发射惯性系中的位置和速度，`m` 为火箭质量；`phi` 和 `psi` 分别为俯仰、偏航程序角。动力学包含：

```text
r_dot = v
v_dot = thrust_acceleration + J2_gravity + aerodynamic_drag
m_dot = -propellant_mass_flow
```

相对气流速度考虑地球自转：

```text
v_rel = v - omega_E × (r + R_launch)
```

当前 S0–S3 策略对比统一采用推力和质量流率同比下降的一级故障模型：

```text
P1_fault    = (1 - kappa) * P1
mdot1_fault = (1 - kappa) * mdot1
```

该模型保持等效排气速度不变，用于近似一级有效推力能力按比例损失。一级理论推进剂耗尽时刻为：

```text
t_depletion = te + (200 - te) / (1 - kappa)
```

## 多阶段处理

故障工况按以下事件分段：

1. 一级故障前：直接使用标称轨迹，不重复优化。
2. 一级故障后：使用衰减后的一级推力和质量流率，重新优化程序角及可选分离时刻。
3. 二级点火至整流罩分离：持续 7 s，使用二级动力学。
4. 整流罩分离后的二级末段：工作时长 `T4` 可按策略固定或优化。

各段分别建立 RK4 动力学约束，避免积分步跨越关机或分离事件。当阶段时长为优化变量时，积分步长同步写为：

```text
dt_i = T_i / N_i
```

一级分离和整流罩分离时，位置与速度保持连续，质量按抛弃结构和剩余推进剂发生跳变；相邻阶段的程序角在事件点保持连续。

## 四类补偿策略

四类策略均允许故障后程序角重新优化，差异只在一级分离时刻和二级末段工作时长是否可调。

| 策略 | 一级分离时刻 | 二级末段 `T4` | 含义 |
| --- | --- | --- | --- |
| S0 | 固定 | 固定 | 无时序补偿基线，仅重构程序角 |
| S1 | 可调 | 固定 | 一级分离时序补偿 |
| S2 | 固定 | 可调 | 二级工作时长补偿 |
| S3 | 可调 | 可调 | 一级与二级联合时序补偿 |

在 `fault_opt_pro.py` 中，命令行策略编号 1–4 依次对应 S0、S2、S1、S3；可达域模块统一使用 S0–S3 名称。

## 优化问题

主要优化变量包括：

- 各离散节点的状态 `X`；
- 故障后的俯仰、偏航程序角 `U`；
- S1/S3 中的一级故障后工作时长；
- S2/S3 中的二级末段工作时长 `T4`。

主要约束包括：

- 分段 RK4 动力学等式；
- 故障点与级间事件的状态连接条件；
- 一级推进剂预算和末端质量下界；
- 程序角范围与俯仰程序角变化率；
- 攻角与 `q-alpha` 气动载荷指标；
- 目标轨道半长轴、偏心率、倾角、升交点赤经、近地点幅角和真近点角约束。

当 `T4` 可调时，内层问题以最小化 `T4` 为主，并使用程序角平滑项作为工程性和数值稳定性的辅助目标。可达边界由外层可行性二分搜索得到：给定 `te`，反复求解不同 `kappa` 下的内层轨迹优化，寻找最大可行推力衰减比例 `kappa_max`。

## 当前结果

现有策略网格包含 93 个故障时刻和 51 个推力衰减比例，共 4743 个网格点/策略。由原始 `reachable` 布尔矩阵统计：

| 策略 | 可达点 | 网格可达比例 |
| --- | ---: | ---: |
| S1 | 387 / 4743 | 8.16% |
| S2 | 2454 / 4743 | 51.74% |
| S3 | 3374 / 4743 | 71.14% |

该比例表示当前均匀参数网格上的可达点占比，不代表实际故障概率或系统可靠度。

代表性工况 `te = 100 s, kappa = 0.4`：

| 指标 | S2：仅二级补偿 | S3：联合补偿 |
| --- | ---: | ---: |
| 一级分离时刻 | 200.00 s | 237.31 s |
| 二级额外工作时长 | 86.25 s | 43.48 s |
| 末端质量 | 57.65 t | 92.30 t |

该工况下，联合策略通过继续利用衰减后的一级推力，将二级额外工作时间减少约 42.78 s，末端质量提高约 34.65 t，体现了一级重力损失与二级推进剂消耗之间的协同权衡。

终端约束对可达域同样有显著影响。例如固定时序、`te = 195 s` 时：

| 终端条件 | `kappa_max` |
| --- | ---: |
| 严格六根数约束 | 0.00154 |
| 放松真近点角 | 0.00390 |
| 工程终端容差 | 0.1278 |

这说明可达性不仅由能量决定，还与轨道相位、控制能力和任务容差定义有关。

## 当前代码结构

### 核心模型

- `core/env_models.py`：环境参数、大气与 J2 重力、坐标转换、轨道六根数。
- `core/rocket_stage.py`：一级/二级三自由度动力学。
- `core/utils.py`：轨迹插值和 RK4 积分。
- `core/ocp_blocks.py`：通用最优控制约束与 IPOPT 配置。
- `core/visual.py`：轨迹、程序角、攻角、速度倾角、动压、`q-alpha` 和轨道结果绘图。

### 当前主线脚本

- `biaozhun_opt.py`：求解标称入轨轨迹，为故障分析提供基线和初始猜测。
- `fault_opt_pro.py`：求解一个指定 `(te, kappa, strategy)` 故障工况，支持四类时序组合。
- `fault_reachability_core.py`：统一构造 S0–S3 故障轨迹优化问题并返回可达性和补偿指标。
- `run_fault_boundary_maps.py`：对每个故障时刻二分搜索 `kappa_max`。
- `run_fault_strategy_maps.py`：扫描 `(te, kappa)` 网格，支持断点续算、边界预筛选和多进程。
- `run_fault_terminal_relaxation_maps.py`：比较严格终端条件、放松真近点角和工程容差。
- `fault_reachability_plots.py`：绘制可达域、一级补偿、二级补偿和策略差值图。
- `dynamics_replay.py`：使用保存的程序角进行独立动力学回放。
- `inspect_npz.py`：检查或对比 `.npz` 结果文件。

旧版实验入口保留在本地研究记录中，不再作为当前主线发布；其演化过程记录在下方更新日志中。

## 运行顺序

建议使用项目虚拟环境，在 Windows `cmd` 中运行：

```bat
.venv\Scripts\python.exe biaozhun_opt.py
.venv\Scripts\python.exe fault_opt_pro.py --strategy 4 --te 100 --kappa 0.4
.venv\Scripts\python.exe run_fault_boundary_maps.py
.venv\Scripts\python.exe run_fault_strategy_maps.py
.venv\Scripts\python.exe run_fault_terminal_relaxation_maps.py
```

批量脚本的 `RUN_SCAN`、`STRATEGIES`、故障网格和并行参数目前在脚本顶部配置。正式扫描前建议先用少量网格点验证约束与初值，再开启完整扫描。

## 模型边界

- 当前为三自由度确定性模型，未包含六自由度姿态、执行机构、结构弹性和推进剂晃动。
- 大气和气动参数经过简化，`q-alpha` 是气动载荷代理指标，不等同于真实结构弯矩。
- 故障假设为瞬时检测、故障后恒定比例衰减，未考虑检测延迟、推力恢复和多故障耦合。
- IPOPT 是局部优化器，单次不收敛不能直接等价为物理不可达。
- `kappa = 0.999` 是当前搜索上限，不代表已经证明完全失去一级推力时仍然可达。

### 2026-05-28：标称轨迹复算与周期角误差修正

- 新生成 `results/biaozhundandao_new.npz`。它与旧 `results/biaozhundandao.npz` 使用相同任务条件，但不要求逐点完全一致。
- 非线性最优控制问题可能因初始猜测、平滑权重、约束开关和求解器收敛路径不同，得到不同但同样满足终端约束的局部解。新旧结果应重点比较末端六根数、`T4`、控制量贴边情况和动力学回放误差，而不是要求 `X/U` 数组逐点一致。
- 将轨道周期角误差从基于 `fmod` 的写法改为基于 `atan2(sin, cos)` 的最短有符号角差，避免跨越 0/360° 时出现错误。例如 1° 与 359° 的差应解释为 2°，而不是 -358°。

当前统一使用：

```python
@staticmethod
def wrap_angle_deg(angle_deg):
    angle_rad = angle_deg * np.pi / 180.0
    return ca.atan2(ca.sin(angle_rad), ca.cos(angle_rad)) * 180.0 / np.pi
```

终端轨道约束对应为：

```python
err_O = env.wrap_angle_deg(O_fin - O_t)
err_w = env.wrap_angle_deg(w_fin - w_t)
err_f = env.wrap_angle_deg(f_fin - f_t)
```
